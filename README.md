# 찬양 반주 피아노 (Worship Piano)

컴퓨터 키보드로 치는 **찬양 반주용 웹 피아노**입니다. 설치도 로그인도 없고, 소리는
브라우저가 직접 합성합니다.

피아노를 못 쳐도 반주가 되도록 만든 것이 핵심입니다.

- **틀린 음이 없습니다** — 쉬운 건반으로 바꾸면 모든 건반이 그 조의 음이 됩니다.
- **어울리는 음을 알려줍니다** — 지금 코드에 맞는 건반이 초록색으로 켜집니다.
- **반주는 알아서 흐릅니다** — 코드만 바꾸면 패턴이 박자에 맞춰 연주합니다.

## 피아노 건반 (기본)

실제 피아노와 같은 배치입니다. 기본 자리가 흰건반, 그 윗줄이 검은건반이고,
검은건반은 흰건반 사이 위쪽에 놓입니다.

```
검은건반    W E     T Y U     O P
흰건반     A S D F G H J K L ;
```

`Q` `R` `I`는 비어 있습니다. 각각 미–파, 시–도 위라서 실제 피아노에도 그 자리에는
검은건반이 없습니다.

옥타브는 흰건반 바로 아랫줄의 `Z` `X`로 올리고 내립니다.

## 쉬운 건반

**건반 배치 → 쉬운 건반**으로 바꾸면 한 건반이 한 계이름이 됩니다. 검은건반이 없고,
손을 기본 자리에 얹으면 바로 도 레 미입니다.

```
한 옥타브 위   Q W E R T Y U I O P
기본          A S D F G H J K L ;
음            도 레 미 파 솔 라 시 도 레 미
```

**어떤 조를 골라도 `A`는 항상 도입니다.** G조든 Eb조든 손가락 순서가 같아서, 조가
바뀌어도 다시 배울 게 없습니다. 조에 없는 음은 건반 자체에 없으니 아무 키나 눌러도
음이 어긋나지 않습니다. 도 자리(으뜸음)에는 위쪽에 금색 띠가 있어 옥타브를 눈으로
찾을 수 있습니다.

## 그 밖의 키

| 키        | 기능                                       |
| --------- | ------------------------------------------ |
| `X` / `Z` | 옥타브 올리기 / 내리기                     |
| `1` ~ `7` | 코드 바꾸기 (누르면 코드도 함께 울립니다)  |
| `Space`   | 서스테인 페달 (누르고 있는 동안 소리 유지) |
| `Enter`   | 현재 코드 한 번 치기                       |
| `\`       | 자동 반주 시작 / 정지                      |
| `Esc`     | 모든 소리 정지                             |

방향키 `↑` `↓`(옥타브), `←` `→`(코드)도 동작합니다. 화면의 건반은 마우스나 터치로
눌러도 소리가 나고, 누른 채 옆으로 끌면 이어서 연주됩니다.

키 입력은 `KeyboardEvent.code`(물리적 키 위치)로 처리합니다. `key`를 쓰면 한글
입력기가 켜져 있을 때 `a`가 `ㅁ`으로 들어와 배치가 통째로 깨지기 때문입니다.
**한/영 상태와 무관하게 연주됩니다.**

## 가장 쉬운 시작

1. **연주 시작**을 누릅니다. 반주가 저절로 흐릅니다.
2. 왼손으로 `1` → `5` → `6` → `4` 를 한 마디씩 눌러 코드를 바꿉니다.
   (가장 흔한 찬양 진행입니다)
3. 오른손은 **초록색 건반**만 눌러 봅니다. 지금 코드의 구성음이라 어느 것을 눌러도
   어울립니다.

코드를 짚는 것도 부담되면 **코드 진행 가이드**에서 진행을 고르고 **진행 자동 넘김**을
켜세요. 마디마다 코드가 알아서 넘어가므로 멜로디만 치면 됩니다.

## 악기: 피아노 · 신디

내가 치는 소리를 고릅니다. 반주 소리와는 별개입니다.

- **피아노** — 치면 감쇠하는 어쿠스틱 소리. 배음을 쌓고 해머 노이즈를 붙였습니다.
- **신디** — 누르고 있는 동안 유지되는 소리. 디튠된 톱니파 2개 + 사각파에 필터
  엔벨로프를 걸어, 찬양팀 신디사이저 특유의 지속음을 냅니다.

## 반주 기능

- **반주 패턴 7종** — 패드, 아르페지오 8비트, 브로큰 코드, 8비트 블록, 6/8 흐름,
  3/4 찬송가, 가스펠 싱커페이션
- **코드 진행 가이드** — 1-5-6-4, 6-4-1-5, 캐논 진행 등
- **화음 색깔** — 3화음 / add9 / sus4 / 7화음
- 12개 조성, 템포 40~160 BPM, 메트로놈, 예배당 잔향(리버브)

코드가 바뀔 때는 **보이스 리딩**이 적용되어, 이전 화음과 가장 가까운 자리바꿈을 골라
연주합니다. 코드를 멀리 건너뛰어도 반주가 옥타브를 널뛰지 않습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
```

React + TypeScript + Vite + Tailwind CSS. 런타임 의존성은 React뿐이고, 소리는 Web
Audio API로 직접 합성하므로 샘플 파일이 없습니다.

## 배포

저장소를 Vercel에 연결하면 추가 설정 없이 배포됩니다. 프레임워크가 Vite로 자동
감지되어 빌드는 `npm run build`, 출력은 `dist`입니다. 정적 파일만 나오므로 다른
정적 호스팅에도 그대로 올라갑니다.
