# 제스처 피아노 · 찬양 반주 (Gesture Piano for Worship)

**찬양 반주를 위한 웹 악기**입니다. 두 가지 방식으로 연주합니다.

- **건반 모드** — 컴퓨터 키보드가 그대로 건반이 됩니다. 피아노와 신디 두 가지 소리.
- **제스처 모드** — 웹캠 앞에서 손을 움직여 연주합니다. 손은 코드만 고르고 반주
  패턴이 알아서 흐르기 때문에, 공중에서 정확한 건반을 짚으려 애쓸 필요 없이
  "화성을 지휘하는" 방식이 됩니다.

어느 쪽이든 자동 반주·코드 진행 가이드를 그대로 씁니다.

- 손 인식: MediaPipe Hand Landmarker (브라우저 안에서만 동작, 영상은 기기 밖으로 나가지 않음)
- 소리: Web Audio API로 직접 합성 (피아노 · 패드 · 베이스 · 메트로놈, 샘플 파일 없음)
- UI: React + TypeScript + Vite + Tailwind CSS

## 제스처 모드 (카메라)

화면은 왼쪽 **코드 영역**과 오른쪽 **멜로디 영역**으로 나뉩니다. 왼손·오른손을 구분하지
않고, **영역에 들어간 손이 그 역할**을 맡습니다. 한 손만으로도 연주할 수 있습니다.

### 코드 영역 (왼쪽)

| 동작               | 결과                                                       |
| ------------------ | ---------------------------------------------------------- |
| 좌우로 이동        | 7칸이 그 조의 1도~7도 코드. 손이 얹힌 칸이 현재 코드       |
| 위아래로 이동      | 손을 높이 들수록 세게, 낮출수록 여리게 (다이내믹)          |
| 엄지 + 검지 붙이기 | 그 자리에서 코드를 한 번 침 (자동 반주 중에도 강세로 사용) |
| 주먹               | 모든 소리 즉시 정지                                        |

### 멜로디 영역 (오른쪽)

| 동작               | 결과                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| 위아래로 이동      | 사다리 한 칸이 한 음. 조의 **5음 음계**라 어떤 코드 위에서도 어긋나지 않음 |
| 엄지 + 검지 붙이기 | 붙이고 있는 동안 소리남. 붙인 채 움직이면 이어서 연주                      |

## 건반 모드 (카메라 없이)

**연주 방식 → 입력 → 건반**을 고르면 카메라를 아예 켜지 않고 컴퓨터 키보드만으로
연주합니다. 화면의 건반을 마우스로 눌러도 소리가 납니다.

키보드 아래 두 줄과 위 두 줄이 각각 한 옥타브씩을 맡는, 트래커·DAW의 표준 배치입니다.

|                          | 흰건반                 | 검은건반          |
| ------------------------ | ---------------------- | ----------------- |
| 아래 두 줄 (기본 옥타브) | `Z X C V B N M , . / ` | `S D  G H J  L ;` |
| 위 두 줄 (한 옥타브 위)  | `Q W E R T Y U I O P`  | `2 3  5 6 7  9 0` |

| 키      | 기능                                         |
| ------- | -------------------------------------------- |
| `Space` | 서스테인 페달 (누르고 있는 동안 소리가 유지) |
| `↑` `↓` | 건반 옥타브 올리기 / 내리기                  |
| `←` `→` | 반주 코드 바꾸기                             |
| `Enter` | 현재 코드 한 번 치기                         |
| `\`     | 자동 반주 시작 / 정지                        |
| `Esc`   | 모든 소리 정지                               |

키 입력은 `KeyboardEvent.code`(물리적 키 위치)로 처리합니다. `key`를 쓰면 한글
입력기가 켜져 있을 때 `z`가 `ㅋ`으로 들어와 배치가 통째로 깨지기 때문입니다.
**한글 상태에서도 그대로 연주됩니다.**

### 악기: 피아노 · 신디

**악기** 선택으로 내가 치는 소리를 바꿉니다. 반주 소리와는 별개입니다.

- **피아노** — 때리면 감쇠하는 소리. 배음을 쌓고 해머 노이즈를 붙인 어쿠스틱 피아노.
- **신디** — 누르고 있는 동안 유지되는 소리. 디튠된 톱니파 2개 + 사각파에 필터
  엔벨로프를 걸어, 찬양팀 신디사이저 특유의 지속음을 냅니다.

흰건반 위의 점은 현재 조성에 속한 음입니다. 그 점만 따라 쳐도 조에서 벗어나지 않습니다.

## 반주 기능

- **반주 패턴 7종** — 패드, 아르페지오 8비트, 브로큰 코드, 8비트 블록, 6/8 흐름,
  3/4 찬송가, 가스펠 싱커페이션
- **자동 반주** — 손은 코드만 고르고 패턴은 템포에 맞춰 스스로 흐름
- **코드 진행 가이드** — 1-5-6-4, 6-4-1-5, 캐논 진행 등. *진행 자동 넘김*을 켜면
  마디마다 다음 코드로 넘어가 손이 멜로디에 집중할 수 있음
- **화음 색깔** — 3화음 / add9 / sus4 / 7화음
- 12개 조성, 템포 40~160 BPM, 메트로놈, 예배당 잔향(리버브)

코드가 바뀔 때는 **보이스 리딩**이 적용되어, 이전 화음과 가장 가까운 자리바꿈을 골라
연주합니다. 손을 크게 움직여도 반주가 옥타브를 널뛰지 않습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

`npm run dev` / `npm run build` 앞에서 `scripts/setup-vision.mjs`가 자동으로 실행되어

- MediaPipe WASM 런타임을 `node_modules`에서 `public/mediapipe/wasm/`으로 복사하고
- 손 인식 모델(`hand_landmarker.task`)을 `public/models/`로 내려받습니다.

둘 다 `.gitignore` 대상이며, 내려받기에 실패하면 앱이 실행 시점에 공개 CDN으로
자동 폴백합니다.

```bash
npm run build    # dist/ 생성
npm run preview
```

## 배포 (Vercel)

저장소를 Vercel에 연결하면 추가 설정 없이 배포됩니다. 프레임워크가 Vite로 자동
감지되어 빌드는 `npm run build`, 출력은 `dist`입니다. 프로덕션 브랜치에 push할
때마다 자동으로 다시 배포됩니다.

빌드 중에 `prebuild` 훅이 손 인식 모델(약 7.5 MB)을 내려받아 `dist/models/`로
함께 올립니다. 즉 **모델과 WASM 런타임을 같은 도메인에서 자가 호스팅**하므로
외부 CDN에 의존하지 않습니다. 빌드 환경에서 내려받기가 막히면 앱이 실행 시점에
공개 CDN으로 자동 폴백하므로 배포가 실패하지는 않습니다.

`vercel.json`은 해시가 붙지 않는 `models/`·`mediapipe/` 정적 파일(합계 약 19 MB)에
30일 캐시 헤더를 지정합니다. 이게 없으면 방문할 때마다 재검증 요청이 나갑니다.

카메라 접근은 브라우저 정책상 **HTTPS 또는 localhost**에서만 동작합니다.
Vercel 배포 URL은 HTTPS라 그대로 됩니다.

## 참고

- 손 인식은 GPU 가속을 사용합니다. 노트북 내장 카메라 기준 30~60 fps에서 가장 자연스럽습니다.
- 조명이 어둡거나 손이 화면 가장자리에 걸리면 인식이 흔들립니다. 상체가 다 들어오도록
  카메라를 조금 멀리 두세요.
- 카메라를 못 쓰는 환경이면 **건반 모드**로 바꾸세요. 카메라를 아예 요청하지 않습니다.
